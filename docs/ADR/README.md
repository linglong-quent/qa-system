# ADR 架构决策记录

## 目录说明

本目录存放玲珑量化 v4.0 的架构决策记录（Architecture Decision Records）。每一条 ADR 记录一个重要的架构决策：上下文、选项、结论、理由、后果。

## 命名规范

- 文件名：`ADR-NNNN-简短标题.md`（NNNN 为四位序号，从 0001 起）
- 标题格式：`# ADR-NNNN: 简短标题`
- 状态：proposed | accepted | superseded | deprecated

## 模板

- 状态: accepted

- 决策者: GOV / KUN / 相关身份
